## Overview

This is the official repository for **Hide-and-Seek in Trajectories: Discovering Failure Signals for VLA Runtime Monitoring**, accepted at **NeurIPS 2026**.

**Hide-and-Seek** is a lightweight runtime failure detector for vision-language-action (VLA) models. It discovers failure-indicative actions using only trajectory-level success/failure supervision, without requiring step-level failure annotations.
